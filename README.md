## 📘 Overview  
This project recreates the **Workout Wednesday 2026 Week 22** challenge — building a **Wind Vector Map** using **Vega‑Lite** inside **Power BI**.  
The visualization shows how **wind speed** and **direction** vary across a region, using color gradients and arrow rotation to reveal flow patterns.

---

## 🧩 Requirements  
- Use the **Deneb visual** to create a wind vector map.  
- Represent **speed** with both color and mark size.  
- Represent **direction** with mark angle (rotation).  
- Use a **wedge** mark so the smaller end points to the direction the wind blows from.  
- Choose a color scheme that clearly shows wind speed patterns — this build uses **Viridis**.  
- Include a legend explaining color, size, and angle.
